Notification keys for The Common Shelf

This page makes the keys push notifications need. They're made here, in your browser: nothing is sent anywhere, and closing the page forgets them. Do this once, then follow the steps it shows. The full setup is in supabase/README.md under "Push notifications".

The private key and the shared secret are passwords. Paste them only where the steps say, and don't send them to anyone (not to Claude either).

1. Supabase → Edge Functions → Secrets: add these four

VAPID_PUBLIC_KEY
VAPID_PRIVATE_KEY
NOTIFY_SECRET
VAPID_SUBJECTmailto: followed by your email address, e.g. mailto:you@example.com

2. Supabase → SQL Editor → New query: paste this and Run

It saves the public key (the app needs it) and the same shared secret for the database.
